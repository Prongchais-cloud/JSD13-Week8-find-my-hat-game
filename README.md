# Thinking Process
ส่วนประกอบมีอะไรบ้าง
1.ส่วนแสดงผล
2.ส่วนรับคำสั่งจากผู้เล่น

## Logic process
- สร้างส่วนแสดงผล จาก array object ที่สร้างจากคลาสต่างๆ
- เริ่มจากสร้าง array object ที่มีแต่ path object ขนาก 10*10
- สุ่มหลุมและใส่ลงไป เช็คด้วยว่าที่ที่จะแทนเป็นหลุมอยู่แล้วรึเปล่า
- สุ่มผู้เล่นและใส่ลงไป เช็คด้วยว่าเป็นหลุมรึเปล่า
- สุ่มหมวกและใส่ลงไป เช็คด้วยว่าต้องไม่เป็นหลุมและผู้เล่น
- สร้างระบบการเดินของผู้เล่นและอัปเดตแผนที่
- เริ่มจากสร้างระบบรับค่าจากผู้เล่น
- สร้างคำสั่งในการขยับตัวผู้เล่น
- สร้างระบบในการอัปเดตแผนที่
- สร้างเงื่อนไขในการจบเกม
- ถ้าออกนอกแผนที่ จบเกมและแสดงข้อความ
- ถ้าตกหลุม จบเกมและแสดงข้อความ
- ถ้าไปถึงหมวก จบเกมและแสดงข้อความ
- สามารถกดออกเกมได้

## ส่วนแสดงผล
- ส่วนประกอบ
1.มีตัวผู้เล่น
2.มีหลุม
3.มีหมวก
- ด่านใช้วิธีสุ่มหลุม สุ่มจุดเกิดของผู้เล่น และจุดเกิดของหมวก

## ส่วนรับคำสั่งจากผู้เล่น
รับคำสั่งจากผู้เล่น (W = ขึ้น/A = ซ้าย/S = ลง/D = ขวา) และแสดงผลการเดินของผู้เล่นลงในส่วนแสดงผล

## ขั้นตอนการทำ
- เริ่มสร้างส่วนแสดงผล
- สร้าง class ของแต่ละ entity (Player, Hole, Path, Hat) โดยสร้างคลาสแม่ชื่อ Entity โดยมีชื่อ(name)และสัญลักษณ์(emoji)
- ใช้ logic ในการสร้างแผนที่ คือ แผนที่เกิดจาก array โดยมีค่าของ class แต่ละคลาส เช่น ช่อง หลุม คือ name="Hole",emoji="🔴" อยู่
- สร้าง array เปล่าๆ ให้มีแต่ทางเดิน(Path) ชื่อ gameMap ใช้วิธี กำหนดจำนวนแถว(rows)และบรรทัด(cols) และใช้คำสั่ง Array.from() สร้าง array ขึ้นมา ให้ชื่อฟังชั้นคือ createMap
- สร้างฟังชั่น randomInt สำหรับสุ่มตำแหน่ง โดยให้ฟังชั้นรับค่าสูงสุดที่เป็นไปได้เพื่อใช้ในการสุ่ม
- สร้างฟังชั่น randomHole ให้สุ่มหลุมใส่ใน gameMap โดยใช้ค่าสุ่มจากฟังชั้น randomInt และใช้ while loop ในการสุ่มวางแต่ละตำแหน่ง และกำหนดจำนวนหลุมที่จะวางด้วยตัวแปล holesToPlace เช็คตำแหน่งที่จะวางว่าเป็นหลุมรึเปล่าโดยกำหนด if(ไม่เป็นหลุ่ม){วางหลุมและลบ holesToPlace ออก 1 หน่วย}
- สร้างฟังชั่น randomPlayer ให้สุ่มผู้เล่นลงใน gameMap โดยใช้ฟังชั่น randomInt และใช้ while loop ในการหาตำแหน่งที่ไม่มีหลุมเพื่อวาง player โดยใช้ if (ไม่เป็นหลุม){วางผู้เล่น} และส่งตำแหน่งของ player ออกมา
- สร้างฟังชั่น randomHat ให้สุ่มหมวกใส่ใน gameMap โดยใช้ฟังชั่น randomInt และใช้ while loop หาตำแหน่งวาง Hat โดยกำหนดเงื่อนไข if(ไม่เป็นหลุมและไม่เป็นผู้เล่น){วางหมวก}
- เอาฟังชั่นสุ่มทั้งหมดใส่สในฟังชั่น createMap และให้ส่ง array ของแผนที่ออกมา
- สร้างตัวแปร location สำหรับใช้หาตำแหน่งของผู้เล่นโดยได้ค่ามาจาก randomPlayer
- สร้างตัวแปร preLocation สำหรับใช้รับตำแหน่งของผู้เล่นก่อนขยับ
- สร้างฟังชั้นในการรับค่าจากผู้เล่นเพื่อเดินไปหาหมวก เริ่มจากสร้างฟังชั้นชื่อ playerInput เพื่อรับค่าจากผู้เล่น (W, A, S, D)
- สร้างฟังชั่น handleCommand เพื่อใช้ในการส่งคำสั่งตามที่ได้รับมาจาก playerInput
- เพิ่มฟังชั่น moveLeft, moveRight, moveUp, moveDown ลงใน Player class
- ใส่คำสั่ง moveLeft, moveRight, moveUp, moveDown ลงในฟังชั่น handleCommand
- สร้างฟังชั่น updateMap สำหรับใช้ในการแสดงผลใหม่หลังจากผู้เล่นขยับ
- สร้างเงื่อนไขของเกมลงใน updateMap

-- ถ้าเดินลงหลุมเกมก็จะจบและแสดงข้อความ 💀 You fell into a hole! Game over.
-- ถ้าเดินไปถึงหมวกเกมก็จะจบและแสดงข้อความ 🎉 You found the hat! You win!
-- ถ้ายังเดินไม่ถึง แผนที่ก็จะอัปเดตตำแหน่งของผู้เล่นและแสดงออกมา
- อัปเดตตำแหน่งของผู้เล่นโดยการใช้ตัวแปร location ใช้อัปเดตตำแหน่งใหม่ของผู้เล่น กับ prelocation ใช้อัปเดตตำแหน่งเก่าให้เป็นทางเดิน
- ใช้คำสั่ง process.exit() ในการจบโปรแกรม
